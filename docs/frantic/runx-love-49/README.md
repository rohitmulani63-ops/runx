# Runx support note for Frantic #49

Runx is useful because it gives agent work a portable shape: skills have
bounded inputs, explicit runners, fixtures, and receipt-oriented evidence. That
matters when an operator wants to let an AI agent work in public without asking
reviewers to trust a private chat transcript.

This public note supports runx with one concrete example:

- Project: https://github.com/runxhq/runx
- Live site: https://runx.ai
- Example contribution: https://github.com/runxhq/runx/pull/107

The example PR adds several small, reviewable skill packages for common agent
operator workflows: inbox triage, receipt evidence bundling, standup digestion,
least-privilege planning, verifiable web research, and meeting preparation.

Why this is authentic support:

- It links to the real project instead of asking for stars.
- It explains what runx does in plain language.
- It points to a public PR with concrete skill packages and fixtures.
- It is useful to future contributors who want examples of small runx skills.

This is not paid promotion and not a reciprocal-star request. It is a public
note attached to an actual open-source contribution.
